# Codex 额度查询工具

查询当前 ChatGPT 账号的 Codex 用量限额：**5 小时窗口 / 每周窗口的剩余百分比（与官方界面同口径）、重置倒计时（精确到分钟）、每张重置卡（限额重置点）的到期时间**。

Chrome 插件版额外提供：**工具栏图标角标常驻显示剩余百分比**（>30% 绿 / 10%-30% 黄 / ≤10% 红，后台每 30 分钟自动刷新）、同账户缓存优先展示、账户选择、Code review 配额 / Credit 余额 / 模型可用性、官方用量页直达、重置卡点击展开发放时间与说明。刷新失败或缓存过期时，角标显示 `!`，鼠标悬停可查看原因。

包含两个可独立使用的版本：

| 目录 | 形态 | 适合场景 |
|---|---|---|
| `local/` | 本地命令行小程序（双击运行） | 平时在电脑上随手查，最稳定 |
| `chrome-extension/` | Chrome 浏览器插件 | 角标常驻监控，点开看详情 |

两个版本调用的是**同一组官方内部接口**，核心额度与重置卡展示口径一致；认证方式不同，插件额外提供上述展示与后台刷新功能。

## 一、本地版使用方法

前置条件：

1. 已安装 Node.js（18 或更高版本，命令行输入 `node -v` 可确认）；
2. 本机 Codex CLI 已用 ChatGPT 账号登录（即存在 `C:\Users\<用户名>\.codex\auth.json`，用 API Key 模式不行）。

使用方法：**双击 `local\查询额度.bat`** 即可。

输出示例（口径与官方「剩余用量」界面一致）：

```text
Codex 额度查询    2026/10/4 10:22:02
账号：xxx@gmail.com    计划：Team    剩余用量 3%
────────────────────────────────────────────────────
5 小时窗口  ████████████ 剩 98%（已用 2%）  10-04 10:27 重置（5分钟后）
每周窗口  ░░░░░░░░░░░░ 剩 3%（已用 97%）  10-09 00:13 重置（4天13小时后）
────────────────────────────────────────────────────
重置卡：可用 3 张
  1. Full reset (Weekly + 5 hr)  10-05 06:48 到期（20小时26分后）  ⚠ 即将到期
  2. Full reset (Weekly + 5 hr)  10-23 04:54 到期（18天18小时后）
  3. Full reset (Weekly + 5 hr)  10-30 03:21 到期（25天16小时后）
```

排查问题时可用命令行模式查看接口原始数据：`node local\codex-quota.js --json`（同时输出限额与重置卡两个接口的原始返回）。

接口结构异常时会明确报错，不能识别的重置卡数据不会显示成“0 张”。主额度失败或结构不可识别时退出码为 `1`；仅重置卡失败时仍展示额度，退出码为 `0`，并尽可能展示额度接口提供的汇总数量。`--json` 保留原始响应，同时通过 `usage_error` / `credits_error` 标注错误。

### 打包成免 Node 的单文件 exe（可选）

exe 只封装查询逻辑，**运行它的机器仍需安装 Codex CLI 并用 ChatGPT 账号登录过**（存在 `~/.codex/auth.json`）——适合发给同样在用 Codex 的合租卡友。

构建（构建机需 Node.js ≥ 22，过程需联网拉取 postject，仅构建期依赖）：

```text
node scripts/build-exe.js
```

构建仅支持 Windows，使用当前运行脚本的 Node 同时生成 blob 和程序壳，注入工具固定为 `postject@1.0.0-alpha.6`。产物先在临时目录构建并校验，再替换稳定 EXE；构建失败保留原 EXE，临时目录自动清理。当前 Node 安装需包含 npm/npx。

产物：`local/dist/codex-quota.exe`（约 100 MB，单文件）。双击运行，查完按回车退出；命令行带参数（如 `--json`）则不暂停，可直接脚本化调用。

注意事项：

- exe 未做代码签名，首次运行可能触发 Windows SmartScreen 提示：点「更多信息 → 仍要运行」；
- 个别杀毒软件可能对注入式打包的 exe 误报，加入白名单即可；
- 产物架构与构建机一致（x64 机器构建出 x64 exe）。

> 重置卡的标题语言跟随账号语言（中文账号显示「完全重置（每周 + 5 小时）」，英文账号显示「Full reset (Weekly + 5 hr)」）。

## 二、Chrome 插件安装方法

1. 打开 Chrome，地址栏输入 `chrome://extensions` 回车；
2. 打开右上角的「开发者模式」开关；
3. 点击左上角「加载已解压的扩展程序」，选择本项目的 `chrome-extension` 文件夹；
4. 确保浏览器已登录 [chatgpt.com](https://chatgpt.com)（插件用网页登录会话查询，读不到本地 auth.json）；
5. 点击浏览器右上角的插件图标即可查询，弹窗内每秒自动刷新重置倒计时和重置卡到期倒计时；工具栏角标每 30 分钟自动更新（也可点弹窗「刷新」立即更新）。

只有一个账户时自动查询；多个账户时，请先在弹窗选择“查询账户”。选择按当前登录用户保存，仅影响本工具，不代表或改变 ChatGPT 网页当前工作空间。后台不会猜测第一个账户，也不会跨登录用户沿用选择。

后台是查询与缓存写入的唯一入口：先确认登录用户和账户，再展示匹配的缓存；主额度获取成功后立即展示，重置卡随后更新。刷新过程中保留已确认属于同账户的内容；登录失效、账户变化或身份无法确认时隐藏旧内容。额度和卡片分别显示真实采集时间，超过 30 分钟或刷新失败的数据明确标注。旧版无账户标识的缓存会自动清除。

## 三、数据来源与安全性

- 限额接口：`GET https://chatgpt.com/backend-api/wham/usage`——这是 Codex CLI 自身轮询的内部限额接口（并非公开 API，社区工具 CodexBar 等均使用同一接口）；
- 重置卡接口：`GET https://chatgpt.com/backend-api/wham/rate-limit-reset-credits`——返回每张重置卡的明细，关键字段：`credits[].status`（available 为可用）、`credits[].title`（类型，如 Full reset）、`credits[].expires_at`（UTC 到期时间，工具内转本地时间显示）；
- 本地版认证：读取 `~/.codex/auth.json` 中的 OAuth token，凭据仅在本次查询的内存中使用，**不落盘、不打印、不发给任何第三方**；
- 插件版认证：先从 `chatgpt.com/api/auth/session` 拿网页会话令牌（accessToken），再带 `Authorization: Bearer` 调用 backend-api 接口；令牌仅存在请求内存中，不写入 `chrome.storage.local`。本地仅保存账户选择、查询结果、采集时间与失败信息，不上传任何第三方；
- 插件权限说明：`alarms` 用于每 30 分钟自动刷新角标，`storage` 用于本地缓存上次查询结果（popup 秒开）；不需要任何敏感权限（无历史记录、无标签页内容读取）；
- 限额接口的关键结构：`rate_limit.primary_window`（5 小时窗口）、`rate_limit.secondary_window`（每周窗口），各含 `used_percent`（已用百分比，工具换算为「剩余」展示）、`reset_after_seconds`（重置倒计时秒数）、`reset_at`（重置时刻 Unix 时间戳）。

## 四、已知限制

- **订阅续费/到期时间**：官方没有干净的公开接口，CodexBar 也是通过网页端 billing 页面会话抓取实现的，本工具暂未包含该功能（注意：这里指账号订阅本身；每张**重置卡**的到期时间已支持）；
- 这两个接口属于非公开内部接口，OpenAI 可能调整字段结构；如显示异常，用 `node local\codex-quota.js --json` 查看原始返回确认；
- API Key 模式（`auth_mode=apikey`）的账号没有订阅额度概念，无法查询。

## 五、常见问题

| 现象 | 处理方法 |
|---|---|
| 本地版提示 401 凭据过期 | 在终端随便运行一次 `codex`（它会自动续期凭据），或重新 `codex login`，再查询 |
| 插件提示「未获取到网页会话令牌」 | 在浏览器打开 chatgpt.com 确认已登录（能正常聊天），然后点插件里的「刷新」 |
| 插件提示 HTTP 401 | 登录已失效，请在 chatgpt.com 重新登录后刷新 |
| 插件提示 HTTP 403 | 核对所选账户权限或网络访问限制，不一定是登录过期 |
| 插件要求选择账户 | 在弹窗选择“查询账户”，选择会按当前登录用户记住 |
| 插件角标显示 `!` | 悬停查看原因，打开弹窗刷新；缓存数据不代表实时额度 |
| 提示网络请求失败 | 检查网络/代理是否可达 `chatgpt.com` |
| 重置卡区域显示「获取失败」 | 限额窗口仍正常（数量会从限额接口的汇总里带出）；点刷新重试，或用 `--json` 查看重置卡接口原始返回 |
| 插件提示「返回结构未识别」 | 接口结构可能变了，把弹窗截图保留下来便于排查 |
